# AUTOMOTIVE OS — Политика безопасности и изоляция

## 1. Multi-Tenant Isolation
- Все запросы проверяют соответствие `organization_id` пользователя запрашиваемому ресурсу.
- Доступ к данным других организаций строго блокируется (Security Test 1/4).

## 2. Location Scoping
- Пользователи с ролью `BRANCH_MANAGER` или `SERVICE_ADVISOR`, привязанные к конкретному филиалу (`location_id`), ограничены своим филиалом (`current_location scope`).
- Роли `OWNER` и `NETWORK_ADMIN` обладают `all_locations scope` для сквозного контроля сети.

## 3. Ролевая матрица (RBAC Guard)
- Все защищенные методы контроллеров декорированы `@RequirePermission('...')`.
- Проверка прав выполняется до выполнения бизнес-логики.
- Механик не имеет доступа к настройкам ролей, бэкапам или аудиту (Security Test 3/4).

## 4. Защита от перебора идентификаторов (UUID Spoofing Prevention)
- Запросы к несуществующим или чужим UUID возвращают `404 Not Found` / `403 Forbidden` без раскрытия деталей структуры данных.

## 5. Неизменяемый журнал аудита (Immutable Audit Logs)
- Записи в `audit_logs` создаются автоматически через `AuditInterceptor` и не подлежат редактированию или удалению.
